# SaveShare v0.1.0 — Première préversion Valheim

Partagez un monde Valheim entre amis sur Windows et macOS, avec un serveur central et un historique des sauvegardes.

## Fonctionnalités

- Envoi automatique des sauvegardes locales `.db` + `.fwl` après stabilisation des fichiers.
- Réception des nouvelles versions ; application automatique activable lorsque le jeu est fermé.
- Session d’écriture exclusive pour passer le relais entre hôtes.
- Historique de versions et restauration d’une ancienne sauvegarde sous forme d’un nouveau commit.
- Vérification SHA-256, sauvegardes de secours et protection des progressions locales non publiées.
- Invitation par monde et déploiement du serveur avec Docker Compose et HTTPS via Caddy.

## Téléchargements

| Fichier | Plateforme |
| --- | --- |
| `SaveShare-0.1.0-Windows-x64.exe` | Windows 64 bits, installateur |
| `SaveShare-0.1.0-macOS-arm64.dmg` | Mac Apple Silicon |
| `SaveShare-0.1.0-macOS-x64.dmg` | Mac Intel |
| `SHA256SUMS.txt` | Empreintes de contrôle des trois installateurs |

Les installateurs incluent le nécessaire pour lancer l’application : Node.js n’est pas requis sur les PC des joueurs. Un serveur SaveShare doit être déployé séparément ; aucun service hébergé n’est fourni.

## Installation et premiers pas

1. Installer l’application correspondant à votre système.
2. [Déployer le serveur HTTPS](https://github.com/martineon/SaveShare#installer-le-serveur-sur-internet), ou demander une invitation à l’ami qui le gère.
3. Utiliser une **copie de votre monde local Valheim** pour le premier essai.
4. Fermer Valheim, connecter le monde, puis prendre la session avant de lancer une partie.
5. Sauvegarder et quitter Valheim avant de terminer la session dans SaveShare.

## État de validation et limites

- Les 11 tests d’intégration du moteur de synchronisation passent localement.
- Le parcours complet de l’interface a été vérifié dans Electron sur Mac : création, publication, passage de session, restauration et invitation.
- Les installateurs Windows x64, Mac Intel et Mac Apple Silicon ont été compilés sur macOS. Leur installation et l’utilisation sur une machine Windows ou Mac Intel restent à valider.
- Aucun test avec une véritable sauvegarde Valheim n’a encore été effectué ; les tests utilisent des fichiers de démonstration.
- Cette préversion n’est pas signée/notariée. Le système peut afficher un avertissement ou bloquer son lancement.
- Les formats Valheim autres que la paire `.db` / `.fwl`, les personnages et les mods ne sont pas synchronisés. Deux progressions concurrentes ne sont pas fusionnées.
- L’application doit rester ouverte. Les invitations donnent accès en lecture et écriture au monde ; elles sont destinées à un groupe de confiance.
