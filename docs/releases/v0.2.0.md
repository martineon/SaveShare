# SaveShare v0.2.0 — Mises à jour de l’application

## Installation initiale

**Installez cette version manuellement une première fois.** La version 0.1.0 ne possède pas de mécanisme de mise à jour. Les mondes connectés, la configuration et les copies de secours restent dans le dossier de données utilisateur.

| Système | Fichier |
| --- | --- |
| Windows x64 | `SaveShare-0.2.0-win-x64.exe` |
| Mac Apple Silicon | `SaveShare-0.2.0-mac-arm64.dmg` |
| Mac Intel | `SaveShare-0.2.0-mac-x64.dmg` |

## Nouveautés

- Vérification des nouvelles versions GitHub dix secondes après le lancement, puis toutes les six heures.
- Bouton de vérification manuelle et affichage de la version installée dans la barre latérale.
- Windows : téléchargement automatique avec progression, puis bouton **Redémarrer et installer**.
- L’installation est bloquée pendant une synchronisation, une session ouverte ou lorsque Valheim est lancé. Quitter normalement l’application ne déclenche pas d’installation.
- Mac : notification des nouvelles versions et bouton **Ouvrir le téléchargement**. L’installation reste manuelle, car les builds ne sont pas signés avec un certificat de distribution Apple.
- Publication des installateurs et des métadonnées de mise à jour après réussite des tests et compilations GitHub sur Windows et Mac.

Les fichiers `latest.yml`, `latest-mac.yml`, `.zip` et `.blockmap` sont utilisés par le mécanisme de mise à jour ; pour une installation manuelle, choisir le `.exe` ou le `.dmg` adapté. Le fichier `SHA256SUMS.txt` permet de vérifier les téléchargements.

Les installateurs restent non signés/notariés. Cette version suit les futures releases publiées sans marqueur « pre-release » ; elle ne redescend pas vers une ancienne version. Le serveur de sauvegardes et son protocole restent compatibles avec 0.1.0.
