# SaveShare 0.4.0 — Prêt dès la connexion

- Option **Ouvrir au démarrage**, activée au premier lancement de l’application installée. Le choix est mémorisé ; une désactivation dans le système n’est pas réactivée silencieusement.
- Vérification et téléchargement du dernier monde dès l’ouverture, puis toutes les 15 secondes. Réessai automatique en cas de réseau indisponible.
- Application automatique activée par défaut et mémorisée pour chaque monde. Aucun remplacement pendant Valheim, une session active ou en présence de modifications locales non publiées. Les copies de secours restent systématiques.
- Notification lorsqu’une version plus récente que la copie locale est téléchargée, sans répétition à chaque vérification. Un clic ouvre le monde concerné dans SaveShare.
- Notification Windows native ; petite fenêtre SaveShare sur Mac, qui fonctionne sans signature Apple. L’application doit rester ouverte pour recevoir les notifications.

## Installation et permissions

Le démarrage automatique se fait à l’ouverture de la session utilisateur, pas avant la connexion. Sur Mac, copier SaveShare dans Applications avant de le lancer. L’application n’étant pas signée/notariée, macOS peut refuser l’enregistrement automatique : ajouter alors SaveShare dans **Réglages Système → Général → Ouverture**. L’interface affiche l’état et les éventuelles restrictions du système.

Les réglages système sont vérifiés avec des doublures de test ; aucun redémarrage réel du PC/Mac n’a été automatisé. Les tests de réception au lancement, protection des fichiers et clic sur la notification sont inclus dans la validation.

Compatible avec le serveur 0.3.0 existant : aucun redéploiement du VPS nécessaire.
