# SaveShare 0.5.1 — Diagnostic de monde

Un nouveau bouton **Diagnostiquer ce monde**, à côté d’**Ouvrir**, aide à comprendre pourquoi un monde partagé n’apparaît pas dans Valheim.

- Dossier configuré, destination exacte et chemin habituel du jeu (indicatif).
- Détection d’un dossier du monde choisi à la place de `worlds_local`, d’un parent choisi trop haut ou de mondes imbriqués.
- Version du serveur, version locale enregistrée, cache téléchargé et fichiers présents réellement distingués.
- Comparaison des empreintes : fichiers manquants, différents ou supplémentaires ; vérification de la structure Valheim.
- Indication des blocages : jeu ouvert, session active, réception désactivée, modifications locales, permissions et journal de restauration interrompue.
- **Copier le rapport** produit un texte partageable sans invitation, clé, pseudo, nom du monde, serveur ni préfixe personnel de chemin. Un aperçu est disponible avant copie.

## Utilisation

Mettre SaveShare à jour chez les deux joueurs, puis, chez le joueur qui ne voit pas le monde : **Diagnostiquer ce monde → Copier le rapport**. Coller ce rapport dans votre discussion de dépannage. Ne pas partager la configuration ou le code d’invitation.

Le diagnostic ne répare rien : aucune sauvegarde déplacée, remplacée ou téléchargée, aucun réglage modifié. Les vérifications d’empreintes sont limitées à 512 Mio et environ 30 secondes ; les vérifications partielles sont signalées. Les permissions sont contrôlées sans écrire de fichier de test.

Un résultat conforme indique que les fichiers correspondent au serveur à la destination configurée, pas que Valheim utilise ce chemin ou accepte les données binaires. Cette version ajoute l’outil de diagnostic ; elle ne prétend pas résoudre à elle seule le problème du monde invisible.

Compatible avec le serveur 0.3.0 existant, sans redéploiement du VPS.

La candidate 0.5.0 n’a pas été publiée : un test comparait mal les chemins courts et longs sous Windows. La validation utilise désormais le chemin canonique sur les deux systèmes.
